# Course material skills

Teachers can use these optional tools to check and maintain the course material they write on [courses.mooc.fi](https://courses.mooc.fi). The tools are skills, written instructions that an AI agent such as Claude Code or Codex follows.

Example use cases:

- **Fact-checking:** check claims against reliable sources and find outdated facts.
- **Links:** find broken or outdated links, images and files.
- **Accessibility:** check alt texts, headings, link texts, tables and contrast.
- **Language:** check spelling, grammar, consistent terms and plain language.
- **Restructuring:** split, merge, move or reorder chapters and pages, then check what the move affected.
- **Language versions:** find where a language version differs from its source and keep the two in line.

Each teacher decides whether to use them and is responsible for the published material.

Teachers: see [SETUP.md](SETUP.md) to set up and use the skills, and please follow your own organisation's rules on AI tools.
