# Reasoning errors

Fallacies, statistical and methodological errors, biases and rhetorical tricks that make weak claims look strong. Read it when checking arguments, statistics or research summaries in course text, or material that teaches students to spot these errors.

## What to check

- **An argument whose conclusion doesn't follow**: look for the patterns in the tables below in explanations, examples and "therefore" sentences. Name the gap and suggest a fix; don't label the text a fallacy. [SEP-Fallacies]
- **A legitimate pattern flagged as a fallacy**: citing relevant experts, or reasoning from consequences, can be sound. Judge the specific use. [SEP-Fallacies] [Goldman-2001]
- **A conclusion called false because its argument is bad**: a failed argument leaves the conclusion unsupported, not refuted. Suggest "this argument doesn't show X" instead. (editorial)
- **Statistics stated without what's needed to read them**: relative risk without absolute risk, a significant result without effect size or uncertainty, a percentage without its base. Suggest adding the missing number. [Gigerenzer-2007] [ASA-2016]
- **Causal language from correlational evidence** ("X leads to Y", "X boosts Y") where the source only shows association. Suggest "is associated with". [Hernan-WhatIf]
- **A null result read as no effect**: a non-significant result from a study too small to detect a meaningful effect presented as proof there is none. Suggest "found no clear effect". [Altman-1995]
- **Weak research presented as solid**: a study presented as solid that shows an error from the methodological errors table, such as exploratory results presented as confirmed. Suggest qualifying it. [Nosek-2018] [Kerr-1998]
- **Exercises that teach an error as correct**, such as an answer key that treats a p-value as the probability the hypothesis is true. Suggest the correct answer with its source. [ASA-2016]

## Background

### Logical fallacies

| Pattern | Problem |
|---|---|
| Straw man, misrepresentation | Attacks a distorted version of the opposing view [SEP-Fallacies] [Cook-2018] |
| Ad hominem | Attacks the person instead of the argument [SEP-Fallacies] |
| Inappropriate appeal to authority | Status offered as proof [SEP-Fallacies] [Cook-2018] |
| Begging the question | The conclusion is assumed in the premises [SEP-Fallacies] |
| False dichotomy | Two options presented when more exist [Cook-2018] |
| Slippery slope | An unjustified chain of escalating consequences [SEP-Fallacies] |
| Hasty generalisation | A broad conclusion from too few or unrepresentative cases [SEP-Fallacies] |
| Appeal to ignorance | No disproof taken as proof, or the burden of proof shifted to critics [SEP-Fallacies] |
| Post hoc, single cause | Sequence taken as cause; one cause given for a many-cause effect [SEP-Fallacies] [Cook-2018] |
| Affirming the consequent | "If A then B; B, so A" [SEP-Fallacies] |
| Equivocation | A word shifts meaning mid-argument [SEP-Fallacies] [Cook-2018] |
| Red herring | An irrelevant point diverts from the question [Cook-2018] |
| Impossible expectations, moving goalposts | Demanding certainty, or raising the bar once it is met [Cook-2018] |
| Motte-and-bailey | A bold claim defended by retreating to a modest one [Shackel-2005] |
| Appeals to nature, tradition or novelty | Natural, old or new taken as better (editorial) |

### Statistical errors

| Error | Problem |
|---|---|
| Base-rate neglect | Ignores how common something is before the new evidence [Gigerenzer-2007] |
| Relative risk alone | "Doubles the risk" without the absolute numbers [Gigerenzer-2007] |
| Misread significance | p < 0.05 read as true, important or large; p > 0.05 read as no effect [ASA-2016] [Altman-1995] |
| No effect size or uncertainty | A precise-looking number with no interval or scale [ASA-2016] |
| P-hacking, multiple comparisons | Flexible analysis or many tests until something is significant [Simmons-2011] |
| Publication bias | Striking positive results overrepresented in what's published [Ioannidis-2005] |
| Small samples | Low power: unreliable and exaggerated effects [Button-2013] |
| Regression to the mean | Extreme scores drifting back mistaken for an intervention's effect [Barnett-2005] |
| Selection and survivorship bias | A sample that excludes failures or isn't the target population [Brown-1992] [Hernan-WhatIf] |
| Confounding, correlation as causation | A third factor or reverse direction explains the association [Hernan-WhatIf] |
| Ecological fallacy | Individual conclusions from group-level data [Robinson-1950] |

### Methodological errors

| Error | Problem |
|---|---|
| No suitable comparison group | No way to tell the effect from change that would have happened anyway [Hernan-WhatIf] |
| Poor measurement, weak construct validity | The measure doesn't capture what the claim is about [Flake-2020] |
| Selective outcome reporting, unhandled missing data | Results depend on what was left out [Cochrane-Handbook] |
| Hypothesising after results are known | Post hoc explanations presented as predictions [Kerr-1998] |
| Exploratory treated as confirmatory | Pattern-finding presented as a tested result [Nosek-2018] |

Statistical sophistication doesn't make the question, measures or conclusions valid. [Flake-2020]

### Biases and epistemic mistakes

| Error | Problem |
|---|---|
| Confirmation bias | Seeking and reading evidence to fit existing beliefs [Nickerson-1998] |
| Motivated reasoning, double standards | Stricter scrutiny for unwelcome evidence than welcome evidence [Kunda-1990] [Taber-2006] |
| Belief perseverance | Keeping a belief after its basis is discredited [Anderson-1980] |
| Essentialism | Complex traits treated as fixed inner essences [Gelman-2004] |
| Teleological explanation | "X exists in order to…" for unintended natural processes [Kelemen-2013] |
| Reification, category errors | Abstractions treated as things; a method applied to the wrong kind of question (editorial) |

### Rhetoric

| Tactic | What it looks like |
|---|---|
| Cherry-picking | Only the favourable studies or data [Cook-2018] |
| Scientific-sounding padding | Neuroscience or technical terms that add no evidence but raise credibility [Weisberg-2008] |
| Conspiracy dismissal | Contrary evidence explained away as a cover-up [Cook-2018] |
