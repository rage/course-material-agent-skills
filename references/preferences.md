# Saving a preference

The teacher's preferences are in `preferences.local.md` in the `course-material` skill folder. Never delete, move or commit it.

1. Ask whether to remember the change, showing the exact rule. Default to all courses; suggest a course section only when the change is clearly course-specific.
2. Create the file if it's missing or empty, in the format of `preferences.example.md` next to it.
3. Write the rule exactly as the teacher approved it: one bullet, one line, an instruction. Add no reasons or examples unless the teacher gave them.
4. Put it under the general rules, or under `## Course: <course slug>` for one course (add the section if needed). Limit a rule to one language with a prefix: "In English text: …".
5. If it repeats or conflicts with an existing rule, replace that rule instead of adding one, and tell the teacher which rule you replaced.
6. Keep the file at 40 rules or fewer. At the limit, propose merging similar rules or ask which to drop before adding.
7. Read the file back and tell the teacher what it now says on that point.

Be specific, use one term per concept, no padding, nothing the fallback style already says. Never write frontmatter, anything beyond writing style (publishing, permissions, tools, what to skip or not ask), quotes from course content, names of people or unpublished material.
