# Course design advice

1. Load the `course-material` skill and write by its **Writing style** rule.
2. Read `course-material/references/guidance/trust.md`.
3. Read the guidance files the request needs:
   - structure, objectives, prerequisites, progression, core content, workload: `course-material/references/guidance/course-design.md`;
   - practice, examples, feedback, how students learn, inclusive design (UDL): `course-material/references/guidance/learning.md`;
   - exercises, assessment, criteria, AI use in graded work: `course-material/references/guidance/exercises.md`;
   - motivation and engagement: `course-material/references/guidance/engagement.md`;
   - planning, evaluating or improving a course or a run: `course-material/references/guidance/course-production.md`;
   - computing, programming and mathematics courses: also `course-material/references/guidance/computing.md`.
4. **A question**: answer briefly with the reasoning and source keys; when the guidance files don't answer it, use the `course-material-research` skill. When it is about the teacher's course, read the outline and the pages it concerns first, and tie the answer to them.
5. **A review of a part**: read `course-material/references/reviewing.md` and follow it for scope, findings and approval. Report from the files' What to check sections.
6. Report and draft only. For approved changes, use the `course-material` skill for text, the `course-material-restructuring` skill for structure, and say what to change in the exercise editor for exercises.

- Whether students can follow the pages in order: use the `course-material-student-walkthrough` skill. Whether chapters teach and practise their objectives: use that skill's Alignment section. Answer keys: use the `course-material-exercise-check` skill.
- Claims about learning made in the material itself ("people learn best in their own learning style"): use the `course-material-claim-check` skill's Check section.
